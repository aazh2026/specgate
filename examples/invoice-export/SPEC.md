# Example: Invoice Export — Specification

A tiny feature spec used to demonstrate `specgate`. Run `specgate` in this
directory to see requirement coverage reported against the code.

## Acceptance Criteria

- [ ] AC-1: User can export invoices as CSV
- [ ] AC-2: Export respects the date range filter
- [ ] AC-3: Exported file is emailed to the account owner
- [ ] AC-4: Export fails loudly when the storage backend is unavailable
- [ ] AC-5: Admin can schedule a recurring monthly export
